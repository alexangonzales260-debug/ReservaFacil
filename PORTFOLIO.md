# PORTFOLIO — ReservaFácil

## Párrafo (3-4 líneas, primera persona)

Construí de cero ReservaFácil, un sistema web de reservas para salones que resuelve un problema real: eliminar el overbooking y reducir los no-shows. El cliente agenda en línea eligiendo servicio, empleado y horario disponible, mientras el dueño gestiona todo desde un panel con reportes de negocio y el sistema bloquea solapamientos automáticamente. Usé Python + Flask, SQLAlchemy, SQLite y Tailwind, con seguridad aplicada (CSRF, contraseñas hasheadas, anti fuerza bruta, secretos por variables de entorno). El proyecto cuenta con 63 tests automatizados sin warnings, desarrollado en 12 fases incrementales con criterio de cierre verificable en cada una.
